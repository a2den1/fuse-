# Fuse

디스코드 계정으로 로그인하면, 내가 속한 서버들의 대화가 **스레드(Threads) 스타일 타임라인 하나**로 모입니다.
채널 트리를 몰라도 커뮤니티에 참여할 수 있게 만드는 것이 목적입니다.

디자인 원칙은 셋입니다. **테두리를 쓰지 않고** 배경 명도 차이로만 면을 나눕니다.
**이모지 대신 스트로크 아이콘**을 씁니다. 움직임은 **스프링 곡선**으로, 아이콘은 서로 모양이 흘러가며 바뀝니다.

Fuse에서 쓴 글은 회원님의 이름과 프로필로 디스코드에 그대로 올라가고,
Fuse에서 단 답글은 디스코드 앱에서도 **스레드**로 보입니다. 양방향으로 동작합니다.

## 바로 실행해보기

```bash
npm install
```

```bash
npm start
```

`.env`가 비어 있으면 **데모 모드**로 뜹니다. 디스코드에 접속하지 않고 예시 서버·대화로
모든 화면과 기능을 그대로 써볼 수 있습니다. 브라우저에서 http://localhost:5195 를 여세요.

## 실제 디스코드에 연결하기

> 자세한 순서와 문제 해결은 [SETUP.md](SETUP.md) 를 보세요.

### 1. 디스코드 애플리케이션 만들기

1. https://discord.com/developers/applications 에서 **New Application**
2. **OAuth2** 탭에서 `CLIENT ID` 와 `CLIENT SECRET` 복사
3. 같은 탭의 **Redirects** 에 아래 주소 추가

   ```
   http://localhost:5195/auth/callback
   ```

4. **Bot** 탭에서 `TOKEN` 을 발급(Reset Token)받아 복사

### 2. 특권 인텐트 켜기 (필수)

**Bot → Privileged Gateway Intents** 에서 두 개를 켭니다.

| 인텐트 | 용도 |
|---|---|
| `MESSAGE CONTENT INTENT` | 글 내용을 읽기 위해 — 없으면 피드가 전부 빈 글이 됩니다 |
| `SERVER MEMBERS INTENT` | 멤버 목록과 권한 계산 |

> 봇이 100개 서버를 넘어가면 디스코드 심사를 받아야 이 인텐트를 계속 쓸 수 있습니다.

### 3. `.env` 채우기

```env
DISCORD_CLIENT_ID=여기에_클라이언트_ID
DISCORD_CLIENT_SECRET=여기에_클라이언트_시크릿
DISCORD_BOT_TOKEN=여기에_봇_토큰

PORT=5195
BASE_URL=http://localhost:5195
SESSION_SECRET=길고_임의의_문자열로_바꾸세요
```

### 4. 서버에 봇 초대하기

OAuth2 → URL Generator 에서 스코프 `bot`, `applications.commands` 를 고르고
아래 권한을 준 뒤 생성된 링크로 초대합니다.

| 권한 | 없으면 생기는 일 |
|---|---|
| 채널 보기 / 메시지 기록 읽기 | 피드에 아무것도 안 뜸 |
| 메시지 보내기 | 글쓰기 실패 |
| **웹훅 관리** | 글이 회원님 이름 대신 봇 이름으로 올라감 |
| 공개 스레드 만들기 / 스레드에서 메시지 보내기 | 답글이 스레드 대신 인용문으로 남음 |
| 메시지 기록 읽기, 반응 추가 | 리액션 동작 안 함 |

봇을 초대한 서버에 **회원님도 가입되어 있어야** 그 서버 글이 피드에 나옵니다.

## 화면

| 화면 | 하는 일 |
|---|---|
| 홈 | 가입한 모든 서버의 글을 한 타임라인으로. 서버별 필터 |
| 글 상세 | 원글 + 답글(디스코드 스레드) + 인라인 답글 입력 |
| 검색 | 글·사람·서버·채널 통합 검색 |
| 알림 | 좋아요·답글·멘션·쪽지 |
| 프로필 | 그 사람이 쓴 글, 함께 있는 서버와 역할 |
| 서버 | 서버 소개, 채널 목록, 멤버 |
| 채널 | 채널 하나만 타임라인으로 |
| 쪽지 | Fuse 안의 1:1 대화 (상대의 디스코드 DM으로도 전달) |
| 서버 둘러보기 | 봇이 있는 서버에 앱 안에서 바로 가입 |
| 설정 | 테마, 애니메이션, 밀도, 시스템 메시지 표시 |

## 기능

- 글쓰기 · 답글 · 인용 · 수정 · 삭제
- 사진/동영상/파일 첨부 (최대 4개, 8MB), 스포일러, 라이트박스
- 좋아요(Fuse 자체) + 리액션(디스코드에 실제 반영)
- `@` 자동완성 멘션, 채널 멘션, 커스텀 이모지, 타임스탬프
- 디스코드 마크다운 전부 (굵게/기울임/밑줄/취소선/스포일러/코드블록/인용/목록/제목)
- 실시간 반영 (새 글, 좋아요, 리액션, 수정·삭제, 입력 중 표시)
- 라이트/다크/시스템 테마, 모바일·데스크톱 반응형

## 알아둘 점

**보이는 범위.** Fuse는 회원님이 디스코드에서 **볼 수 있는 채널만** 보여줍니다.
매 요청마다 역할·채널 권한 오버라이트를 그대로 계산하며, 실시간 이벤트도 같은 검사를 통과해야 전달됩니다.

**글쓴이 표시.** Fuse에서 쓴 글은 웹훅으로 회원님의 이름·프로필 사진을 달고 올라갑니다.
디스코드 공식 기능이며, 계정 토큰은 어디에도 쓰지 않습니다.

**수정·삭제.** Fuse에서 쓴 자기 글만 가능합니다. 디스코드 앱에서 직접 쓴 글은 손댈 수 없습니다.

**좋아요와 리액션은 다릅니다.** 하트는 Fuse 안에서만 집계됩니다.
이모지 리액션은 봇이 대신 눌러 디스코드에도 실제로 반영되며, Fuse 사용자가 모두 취소하면 봇도 뗍니다.

**할 수 없는 것.** 디스코드 API가 서드파티 앱에 열어주지 않는 영역입니다.

- 기존 DM과 그룹 DM 읽기 — 어떤 스코프로도 불가
- 친구 목록 — 화이트리스트 전용 스코프
- 음성/화면공유 — 봇은 참여만 가능하고 사용자를 대신할 수 없음

쪽지 기능은 이 한계 안에서 만든 **Fuse 자체 대화**입니다. 기존 디스코드 DM과는 별개 공간이며,
상대에게는 봇 DM으로 알림이 가고 거기에 답장하면 Fuse로 돌아옵니다.

## 구조

```
src/
  index.js          Express + WebSocket 부팅
  config.js         .env 로딩 (경로 고정, override)
  session.js        서명 쿠키 세션
  db.js             JSON 파일 저장 (좋아요·알림·설정·쪽지)
  store.js          채널별 메시지 캐시 (스노우플레이크 정렬)
  realtime.js       WebSocket 허브 — 채널 가시성 검사 후 전달
  hydrate.js        뷰어별 필드(좋아요·권한·멘션) 채우기
  service.js        프로바이더 중립 로직 (라우트가 부르는 유일한 계층)
  routes/           auth · api · demo 자산
  discord/          bot · permissions · webhooks · normalize
  demo/             목 백엔드 + 이미지 크기 파서
public/
  index.html        앱 셸
  login.html        로그인
  assets/js/        app(라우터) · views · post · compose · mention · markdown · live · dom · api · state
  assets/js/icons.js  자동 생성 아이콘 데이터 (직접 고치지 말 것)
  assets/css/       app.css
scripts/
  build-icons.mjs   Lucide → 단일 path 데이터 생성
```

데이터는 `data/db.json` 에 저장됩니다. 지우면 좋아요·알림·쪽지가 초기화됩니다.

## 아이콘

아이콘 폰트를 쓰지 않습니다. [Lucide](https://lucide.dev) 스트로크 아이콘을
[morphicons](https://www.morphicons.com) 의 `canonicalD` 로 **하나의 `path` 데이터**로 눌러
`public/assets/js/icons.js` 에 넣어두고, 화면에서는 인라인 SVG로 그립니다.

전부 같은 24×24 그리드 위에 있어서 서로 모양이 흘러가며 바뀝니다.
복사 버튼을 누르면 종이 아이콘이 체크로 변형되는 식입니다.

아이콘을 더하거나 빼려면 `scripts/build-icons.mjs` 의 목록을 고치고

```bash
npm run build:icons
```

`morphicons` 런타임은 `/vendor/morphicons/` 로 그대로 서빙됩니다 (의존성 없는 ESM).
